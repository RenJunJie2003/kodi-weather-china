# 中文输入、UTF-8 编码与 strings.po 多语言本地化

## 1. 中文城市名输入链路

```
Kodi 用户（遥控器/键盘/手机 Kodi 遥控 App）
   │  输入「石家庄」
   ▼
lib/ui.py :: xbmcgui.Dialog().input(heading=L(32104), type=INPUT_ALPHANUM)
   │  Python 3 str（Unicode），Kodi 返回已是 UTF-8 解码后的字符串
   ▼
CityDB.search(query)
   │  norm_city()/norm_prov() 去后缀（市/区/县/省/自治区…）
   │  评分：精确 > 前缀 > 包含 > 所在省包含
   │  在 resources/data/cities_nmc.json（2529 站点）里检索
   ▼
结果列表：「石家庄 · 河北省」，同时携带 nmc_code 与 wcn_code
   │  点击后生成插件 URL：
   │  _url("city_select", name="石家庄", code="101090101"?…, wcode="101090101")
   │      urllib.parse.urlencode(data, encoding="utf-8")
   │      → name=%E7%9F%B3%E5%AE%B6%E5%BA%84
   ▼
Kodi 再次调用 default.py，sys.argv[2] = "?action=city_select&name=%E7%9F%B3…"
   │  urllib.parse.parse_qs(query, encoding="utf-8", errors="replace")
   ▼
config.put("city_name", "石家庄") → 写入 Kodi 设置 → 清缓存 → 重新抓取 → 刷新界面
```

**关键点**

1. 中文参数**必须显式** `urlencode(encoding="utf-8")` / `parse_qs(encoding="utf-8")`，否则在部分平台会按系统默认编码（如 cp1252）解码成乱码。
2. 搜索输入本身不经过 URL（用 `Dialog().input()` 直接得到 Python `str`），只有「选中结果」这一步需要编码传递；中文名同时也写进 Kodi 设置（Kodi 设置文件为 UTF-8）。
3. 支持中文子串（「朝阳」可找到北京朝阳区 / 辽宁朝阳市）、去后缀归一化（「北京市」=「北京」）、热门城市 24 个、拼音首字母快捷（`bj`/`sh`/`sjz`…）。
4. 输入非中文纯字母时自动走拼音首字母表；无匹配时提示改用更短关键词。

## 2. UTF-8 编码处理清单

| 环节 | 处理 |
|---|---|
| 网络响应 | `raw.decode("utf-8", "replace")`；统一在 `lib/net.py::_request()`，不在各解析模块重复解码 |
| 请求头 | `Accept-Charset: UTF-8,*;q=0.5`、`Accept-Language: zh-CN,zh;q=0.9` |
| JS 变量响应 | 中国天气网返回 `text/html` 但实体为 UTF-8；按 UTF-8 解码后 `json.loads`（中文直接可用） |
| 缓存文件 | `open(..., encoding="utf-8")` 写 `json.dump(ensure_ascii=False)`；读同样 UTF-8 |
| 内置数据 | `cities_*.json` / `conditions.json` 均为 UTF-8 无 BOM，`ensure_ascii=False` 保留中文 |
| 语言文件 | `strings.po` 头部 `Content-Type: text/plain; charset=UTF-8`，文件 UTF-8 无 BOM |
| XML | `addon.xml` / `settings.xml` 首行 `<?xml version="1.0" encoding="UTF-8"?>` |
| Python 源码 | 全部 `# -*- coding: utf-8 -*-` + `from __future__ import unicode_literals` |
| 插件 URL | `urlencode` / `parse_qs` 显式 `encoding="utf-8"` |
| 日志 | `xbmc.log()` 传 Python `str`，由 Kodi 按 UTF-8 写入 `kodi.log` |
| 用户数据目录 | 在线刷新的 `cities_nmc.json` 同样 UTF-8 写入 |

> 不做 GBK/GB2312 猜测：实测 `nmc.cn` 的 404 页面声明 `gb2312`，但数据接口和 `weather.com.cn` 页面实体都是 UTF-8。统一按 UTF-8 是最稳的策略。

## 3. strings.po 本地化实现

### 3.1 目录约定

Kodi 按 `resources/language/resource.language.<lang>/strings.po` 加载。`lang` 跟随 Kodi 系统语言：

- `resource.language.zh_cn` → 中文(简体)
- `resource.language.en_gb` → English (UK)
- 找不到对应语言时 Kodi 回退到 `en_gb`（本项目保证 en_gb 完整）

### 3.2 文件格式

```po
# Kodi Media Center language file
msgid ""
msgstr ""
"Content-Type: text/plain; charset=UTF-8\n"
...

msgctxt "#32100"
msgid "Current conditions"
msgstr "实时天气"

msgctxt "#32102"
msgid "Weather alerts"
msgstr "气象预警"
```

- `msgctxt "#32xxx"` 是 Kodi 要求的固定写法（`#` + 数字）。
- `msgid` 恒为英文原文，`msgstr` 为目标语言译文。
- 代码中统一用 `config.L(32100)` 取词（`ADDON.getLocalizedString(32100)`），支持 `{0}` 占位符：`L(32114, name)`。
- **UI 代码零硬编码中文**；所有可见文字都来自 strings.po。

### 3.3 编号规划

| 区间 | 用途 |
|---|---|
| 32000–32004 | settings.xml 分类 / 分组标题 |
| 32010–32046 | settings.xml 的 label、help 与 option 文本 |
| 32100–32178 | 菜单、页面、字段、提示、通知等界面文本 |
| 32200–32206 | 星期一 ~ 星期日 |

预留空段便于后续新增（如逐小时预报、雷达页面）。

### 3.4 单一字符串表生成（避免中英条目不一致）

`tools/gen_language.py` 维护唯一一份 `STRINGS = {id: (中文, 英文)}`，一次运行同时写出两个 `strings.po`：

```bash
python tools/gen_language.py
# 生成 …/resource.language.zh_cn/strings.po (128 条)
# 生成 …/resource.language.en_gb/strings.po (128 条)
```

好处：新增界面文本只需在一处加一行，两个语言的 `msgctxt` 集合必然完全一致。`tools/selftest.py` 会校验：
- 中英条目数一致；
- `settings.xml` 引用的每个 32xxx 编号在语言文件中都存在；
- 中文文件确实含中文、英文文件确实含英文。

### 3.5 addon.xml 的双语元数据

Kodi 插件管理器里显示的说明也支持多语言，直接用 `lang` 属性：

```xml
<summary lang="zh_CN">中国天气：实时天气、多日预报…</summary>
<summary lang="en_GB">China Weather: current conditions…</summary>
<description lang="zh_CN">…</description>
<description lang="en_GB">…</description>
<disclaimer lang="zh_CN">…</disclaimer>
```

### 3.6 新增一种语言（例如繁体中文）

1. 复制 `resource.language.zh_cn` → `resource.language.zh_tw`，把 `strings.po` 的 `msgstr` 改为繁体，`Language:` / `Language-Team:` 改为 `zh_tw` / `Chinese (Traditional)`。
2. 或在 `tools/gen_language.py` 的 `STRINGS` 增加第三个语言列并扩展 `render()` / `targets`（推荐长期维护）。
3. 在 `addon.xml` 里补 `<summary lang="zh_TW">…</summary>`。
4. 运行 `python tools/selftest.py` 确认条目一致；Kodi 里把系统语言切成繁体中文验证。
5. 运行 `python tools/make_release.py` 重新打包。

## 4. 中文界面还需要什么

| 项 | 说明 |
|---|---|
| Kodi 系统语言 | 设置 → Interface → Regional → Language → 中文(简体) |
| 字体 | Kodi 默认字体（如 Arial based / Noto）通常含中文字形；若显示方框，换用含 CJK 的皮肤字体 |
| 输入法 | 电视端建议用手机 Kodi 遥控 App（Kore / 官方 Remote）输入中文，比遥控器软键盘方便 |
| 数据源内容 | 预警全文、天气现象、城市名本身就是中文，英文界面下这些**内容仍为中文**（源数据性质，非乱码） |

常见乱码排查见 [INSTALL_DEBUG.md](INSTALL_DEBUG.md#常见问题)。
